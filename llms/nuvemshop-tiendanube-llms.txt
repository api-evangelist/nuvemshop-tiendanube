# Nuvemshop Tiendanube

> Nuvemshop (Tiendanube in Spanish-speaking markets) is the leading e-commerce platform in Latin America. Its REST API lets partners build public apps and integrations that manage products, orders, customers, categories, coupons, shipping, locations, metafields, scripts and webhooks. Apps use a restricted OAuth 2 authorization-code flow with non-expiring bearer tokens, a leaky-bucket rate limit, and HMAC-SHA256-signed webhooks.

## APIs

- [Nuvemshop Tiendanube API](https://tiendanube.github.io/api-documentation/intro): REST API, base URL https://api.tiendanube.com/2025-03/{store_id} (also api.nuvemshop.com.br). Date-based versioning (current 2025-03, legacy v1).
