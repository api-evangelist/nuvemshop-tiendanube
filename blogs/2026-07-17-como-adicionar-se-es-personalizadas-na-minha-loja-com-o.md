Com as seções personalizadas, você pode montar suas próprias seções dentro do editor do layout Ipanema combinando os blocos que quiser : botão, imagem, título, descrição, separador e grupo. Você também pode adicionar um bloco de código próprio para inserir HTML, CSS e JavaScript diretamente na sua loja, sem abrir o FTP. Essa funcionalidade te dá liberdade para criar layouts sob medida, sem depender das seções predefinidas .
