O ID da categoria é um código numérico único que identifica cada categoria de produtos da sua loja. Este dado é indispensável para poder criar cupons de desconto que se apliquem apenas a determinadas categorias nas suas campanhas do Nuvem Marketing . Helpjuice Info Callout Title Como não é possível exportar esses dados de forma massiva, o processo de coleta deve ser realizado manualmente.
