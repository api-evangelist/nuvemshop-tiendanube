Editar o código CSS da sua loja permite fazer pequenas modificações no layout , sem precisar mexer no código HTML: mudar cores, ocultar elementos, modificar tamanhos ou reorganizar a posição do que já existe. Não é possível criar elementos novos, apenas modificar o estilo dos que já fazem parte do seu layout. Para aproveitar melhor as diferentes possibilidades de personalização com CSS, é recomendável ter um conhecimento básico dessa linguagem.
