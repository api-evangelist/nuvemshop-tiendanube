Na ferramenta de Ponto de Venda (PDV) , você pode conectar um leitor de código de barras para adicionar produtos no carrinho de forma fácil e rápida, permitindo buscar e incluir os produtos que o cliente deseja comprar em questão de segundos. A seguir, vamos te mostrar os passos a seguir para conectar um leitor de código de barras para escanear os produtos. Atenção aos requisitos: É necessário ter um dispositivo que permite a leitura de códigos de barras .
